# 🍽️ CanteenApp

A comprehensive digital canteen management system designed specifically for university environments, connecting students with campus food vendors through a seamless React-powered platform.

## 📖 About The Project

**CanteenApp** is a modern web application that revolutionizes the university dining experience by providing a dual-sided platform for both students (*mahasiswa*) and food vendors/sellers. Built with React and powered by Supabase, this application streamlines food ordering, payment processing, and vendor management within campus canteens.

### 🎯 Key Features

#### For Students (Mahasiswa)
- **Vendor Discovery**: Browse and explore various canteen vendors
- **Easy Ordering**: Simple and intuitive food ordering interface
- **Order Tracking**: Real-time order status monitoring
- **Profile Management**: Personal account and preference settings

#### For Vendors/Sellers
- **Dashboard Analytics**: Comprehensive sales dashboard with visual charts
- **Order Management**: Real-time order processing and status updates
- **Product Management**: Easy product catalog management
- **Revenue Insights**: Daily earnings tracking and analytics
- **Performance Metrics**: Rating system and customer feedback

## 🏗️ Built With

- **Frontend**: React 19.0.0 with Vite
- **Backend**: Supabase (Database & Authentication)
- **Styling**: Tailwind CSS with DaisyUI components
- **Charts**: Chart.js with React-Chart.js-2
- **Icons**: Lucide React & React Icons
- **Routing**: React Router DOM
- **Date Handling**: Luxon
- **Security**: bcrypt.js for password hashing
